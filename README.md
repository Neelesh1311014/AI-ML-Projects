# 🚀 Major Project — DDoS Attack Detection Using Machine Learning

### 🎯 Objective

Develop a Machine Learning-based system to detect **DDoS attacks** in network traffic.

### 🛠️ What I Did

- Worked with network traffic data containing **BENIGN and DDoS** traffic.
- Selected relevant network traffic features.
- Performed data preprocessing.
- Applied feature scaling.
- Trained a **Random Forest Classifier**.
- Trained a **Support Vector Machine (SVM)** classifier.
- Combined the predictions of both models.
- Evaluated the models using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
- Saved trained Machine Learning models using **Joblib**.
- Developed a **Flask web application** for prediction.
- Added CSV file upload functionality.
- Generated prediction results for uploaded network traffic data.
- Displayed prediction results using **Pie Charts**.
- Displayed prediction counts using **Bar Charts**.
- Added options to download generated prediction results as CSV files.
- Added an option to upload another file for prediction.

### 🌐 Web Application

The web application allows users to:

1. Upload a CSV network traffic file.
2. Process the uploaded data.
3. Generate DDoS and BENIGN predictions.
4. View prediction results.
5. View graphical representations of predictions.
6. Download prediction results as CSV files.
7. Upload another file for prediction.

### 💻 Technologies

**Python, Pandas, NumPy, Scikit-learn, Matplotlib, Flask, Joblib, HTML, CSS**
